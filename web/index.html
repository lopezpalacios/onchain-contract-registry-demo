The control question

Is the code on chain the code that was approved, for the request that was approved? A repository cannot answer that. A block explorer cannot answer that. The registry links the two records.

A pre-chain record is a deployment request plus template, config hash, manifest hash and approvals. The on-chain record is only created after the deployment transaction. The link is the request ID, deployment transaction and bytecode hash match — not a spreadsheet note.
